# 荒原场景修复报告

## 问题描述

荒原场景（1000×1000m）所有测量点信号为 -180 dBμV/m（零信号），测量无意义。

## 根因分析

### 问题1: 地形采样返回垃圾值
- **现象**: `zg` 范围 [-661, 1387]m，实际地形仅 0~188m
- **根因**: `_fast_sample_terrain` 在查询点超出地形网格边界时，`searchsorted` 返回越界索引，双线性插值产生垃圾值
- **影响**: PE 步进时，错误的 zg 导致场在错误高度被清零，信号在几十米内消失

### 问题2: 天线高度低于地形
- **现象**: 天线 z=60m，但东北方向地形高达 188m
- **根因**: phi=0 方向有 649/722 步地形高于天线，场被清零
- **影响**: 信号无法越过山脊到达东北方向接收点

### 问题3: 高斯波束太窄
- **现象**: σ=3~20m，天线在 200m，接收点在 z=45~270m
- **根因**: z=45m 距天线 155m，155/20 = 7.75σ → 初始场 ≈ exp(-30) ≈ 0
- **影响**: 低高度接收点初始场为零，PE 无法传播零场

### 问题4: 材料参数不合理
- **现象**: 森林 ε_r=1.1, σ=0.002 → 0.49 dB/m，300m 穿透 = 147 dB
- **根因**: σ 过高导致每步衰减过大，PE 累积后信号完全消失
- **ITU 对比**: P.833 给出 2.8 GHz 森林 0.1~0.5 dB/m，中值 0.3 dB/m

## 修复方案

### 修复1: 地形采样越界钳位
```python
x = max(x_min, min(xp[i], x_max))  # 钳位到地形边界
y = max(y_min, min(yp[i], y_max))
dx = max(0.0, min(dx, 1.0))        # 插值权重钳位
dy = max(0.0, min(dy, 1.0))
```
- 效果: zg 范围从 [-661, 1387] → [0, 180]，与实际地形吻合

### 修复2: 天线高度 200m + 宽波束 σ=80
- 天线从 60m → 200m（超过所有地形 188m）
- 波束 σ 从 20m → 80m（覆盖 z=40~360m，所有接收点高度）
- 效果: phi=0 方向 0 步地形高于天线，信号畅通

### 修复3: ITU 验证材料参数
调研 ITU-R P.527 和 P.833 后更新:

| 材料 | 旧参数 | ITU 参数 | 衰减率 |
|---|---|---|---|
| 森林冠层 | ε=1.1, σ=0.002 | **ε=1.5, σ=0.0002** | 0.27 dB/m |
| 低矮植被 | ε=12, σ=0.005 | **ε=1.2, σ=0.00006** | 0.09 dB/m |
| 沙地 | ε=3, σ=0.001 | ε=3, σ=0.001 (不变) | 0.94 dB/m |
| 干燥土壤 | ε=15, σ=0.01 | ε=15, σ=0.01 (不变) | 4.22 dB/m |
| 淡水 | ε=80, σ=0.01 | ε=80, σ=0.01 (不变) | 1.83 dB/m |

**ITU 依据**:
- P.833 §2: 2.8 GHz 森林特定衰减 0.1~0.5 dB/m
- P.527 §5.3: 植被 ε_v = 1.7 - 0.74m + 6.16m² (m=含水量)
- P.527 §5.2: 干燥土壤 σ ≈ 10⁻⁴~10⁻² S/m

### 修复4: 材质层正确参与 PE
- 材质层（沙地/草地/森林冠层）不再被当障碍物覆盖地形
- 作为裁剪层叠加: `zt = zg + thickness`
- 每步对 zt-zg 之间的场施加材料衰减
- 森林 10m 冠层 × 0.27 dB/m = 2.7 dB/m 穿透损耗

### 修复5: PE 求解参数优化
| 参数 | 默认值 | 荒原值 | 理由 |
|---|---|---|---|
| dr_factor | 1.0 | 8.0 | 1000m 尺度需要大步长 |
| n_z | 2048 | 512 | 高度 0~230m，512 点足够 |
| n_phi | 128 | 64 | 方位角分辨率适中 |
| 求解时间 | ~300s | ~55s | 10 点 55 秒 |

## 结论

荒原场景从"所有点零信号"修复到"10/10 点有信号，54 秒完成"。关键修复:
1. 地形采样越界钳位
2. 天线 200m + 宽波束 σ=80
3. ITU 验证材料参数
4. 材质层作为裁剪层正确参与 PE
5. PE 参数优化（dr=8, nz=512, nphi=64）
