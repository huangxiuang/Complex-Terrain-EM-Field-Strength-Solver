EM Solver — 用户使用指南

柱坐标系抛物方程（CPE）电磁场求解器，用于 2.8 GHz S 波段地波传播、障碍物绕射与复杂环境覆盖分析。支持 4 个预置场景、5 种天线类型、12 种可编辑材料、DEM/ASC 导入导出。

快速开始

pip install -r requirements.txt
python src/main_window.py

启动后自动加载金属挡板场景。窗口左侧为树形导航，中央为3D 视图，顶部为菜单栏，底部为状态栏。

CLI 模式：

python run.py --freq 2.8e9 --tx="-400,0,200" --nz=1024 --dr=8.0 --plot

测量点

  • 精准添加（双击➕添加）：步骤1 XY选点 → 步骤2 调Z高度
  • 快速添加（菜单 工具→快速添加）：XY点击，统一Z
  • 管理（菜单 工具→管理）：表格编辑/删除/导入CSV/导出CSV
  • 右键树中测量点可删除或清空；双击编辑坐标（自适应场景范围）
过近点（距天线<r₀=2λ）会被自动剔除。

求解

添加点后，点击⚡求解。求解在后台线程运行——可继续旋转缩放视图。完成后自动显示结果表（E高亮蓝/L_fs绿/L_pe橙），📊画图按钮激活。求解期间修改场景，结果基于快照，会弹出提醒。

常见问题

所有点为 -180 dBμV/m

天线高度低于地形。菜单 参数→天线设置 提升天线。荒原场景建议200m+。

高度网格过粗警告

Δz > λ/2 时触发。大场景有意的精度换速度权衡。增大 N_Z 可消除。

导入DEM失败

需 pip install rasterio。确认文件为 GeoTIFF/IMG 格式。

求解时间过长

增大 dr_factor、减小 N_Z/N_φ、减少测量点。扫频快速模式约4×加速。
