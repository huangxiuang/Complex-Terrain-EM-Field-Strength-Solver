EM Solver — 用户使用指南

柱坐标系抛物方程（CPE）电磁场求解器，用于 2.8 GHz 频段地波传播与障碍物绕射分析。

快速开始

pip install -r requirements.txt
python src/main_window.py

启动后自动加载默认场景（金属挡板），窗口左侧为树形导航，中央为3D 视图，顶部为菜单栏，底部为状态栏。

工具栏

求解按钮右侧依次为：⚡求解、📊画图、待求解点数标签。

场景管理

菜单 场景 → 场景选择 打开场景列表，可选：

场景内容用途
金属挡板平坦地面 + 铝墙 + 天线经典 knife-edge 绕射
自然景观高斯山丘 + 正弦河道 + 植被 + 鸟 + 树 + 天线复杂地形传播
城市街区平坦地面 + 4 栋混凝土建筑 + 天线城区多径与遮挡

切换场景会清空测量点和求解结果。菜单 场景 → 场景属性 查看当前场景所有对象的详细参数（材料、尺寸、位置）。

测量点

添加测量点

双击树中 ➕添加，弹出精准添加对话框：

  • 步骤 1/2：在 XY 平面上点击添加点，或手动输入 X/Y 坐标
  • 步骤 2/2：在高度图上调整每个点的 Z 坐标

添加不会清除已有测量点。管理测量点（菜单 工具 → 管理测量点）可查看/编辑/删除全部点。

编辑/删除

  • 右键测量点 → 🗑删除（同步删除对应结果，编号自动顺位）
  • 双击测量点 → 弹出 X/Y/Z 编辑框

求解

添加测量点后，双击树中 ⚡求解 或点击工具栏按钮。

求解完成后：

  • 弹出 结果表格（可关闭）
  • 树中出现 📊 Results 节点
  • 📊画图 按钮激活

求解耗时与测量点数量无关——PE 必须从天线推到最远点，1 个点和 10 个点耗时相同。慢是因为进度条在格式化结果。

画图

求解后双击 📊画图，弹出参数设置窗口：

  1. 勾选要生成的图类型（可多选）
  2. 设置参数：r-z 图需选 φ 角（−90°~90°），φ-z 图需选距离 r，损耗曲线需选高度 z
  3. 点击 ▶生成

生成后弹出独立大窗口（1000×700），标签页显示每张图：

图色标说明
r-z 传输损耗分布jet（蓝→红）距离-高度 TL 等高线，固定 φ
r-z 电场分布inferno距离-高度 |E| 伪彩图
φ-z 传输损耗分布jet（蓝→红）方位角-高度 TL，x 轴 −90°~90°
路径损耗 vs 距离—固定高度处 TL 曲线
场强 vs 高度—固定距离处 |E|+TL 双图
TL 3D 表面jet三维曲面

每张图可导出 PNG / PDF / SVG，也可一键导出全部。

绘图范围为"天线到最远测量点"之间的空间。地面以下及天顶吸收层无有效数据。TL 参考基准统一为 r₀ 处天线高度 φ=0 的场强。

扫频模式

菜单 工具 → 扫频模式（Ctrl+S）：

  • 设置频率范围、步数、线性/对数刻度
  • 快速模式（默认）：N_Z=1024, N_PHI=64，约 4× 加速
  • 点击开始扫频，进度条实时显示
  • 结果表格 + 绘制曲线 + 导出 CSV

天线设置

菜单 参数 → 天线设置：

  • 5 种天线类型：高斯波束 / 半波偶极子 / 微带贴片 / 喇叭 / 全向
  • 可调参数：σ_z、俯角、HPBW
  • 右侧实时预览全圆方向图（极坐标）
  • 天线位置 X/Y/Z 可直接编辑（修改后 3D 标记同步更新）

默认：高斯波束 σ=4.0m（垂直 HPBW≈110°）。

材料参数

菜单 参数 → 材料参数设置：

  • 首行固定显示空气（ε_r=1.0006, σ=0），可编辑（模拟潮湿天气）
  • 所有 EM 相关对象的 ε_r、σ、厚度均可调
  • 修改后自动重算复折射率 Re(n)/Im(n)
  • 支持导出/导入 JSON

图层管理

菜单 图层：

  • 增加图层：选择材料 → 在 XY 平面上绘制形状（矩形/方形/三角/圆形/多边形），裁剪地形生成新图层
  • 管理裁剪图层：调整已创建图层的可见性和透明度

字段含义单位

Δ = L_pe − L_fs：正值 = 额外损耗（绕射/吸收/天线方向图衰减），近 0 = 自由空间传播。

物理说明

为什么近地损耗大？

三个效应叠加：天线方向图（主波束指向水平，低处能量先天不足）+ 地面反射在掠入射时相消（直达波和反射波等幅反相）+ DMFT 有损地面吸收。

为什么土山挡不住信号？

干燥土壤（ε_r=15, σ=0.01）对 2.8 GHz 穿透深度约 2m（−8.7 dB）。5m 山丘纯穿透损耗约 21 dB，但绕射从山顶以上填补阴影，实际额外损耗只有几 dB。要让山体有效阻挡，需湿土（σ=0.1）或金属障碍物。

TL 参考基准

所有传输损耗图统一参考 r=r₀ 处、天线高度、φ=0 的场强。不同方向/高度的 TL 都相对此基准计算。

常见问题

软件打不开

确保在项目根目录运行 python src/main_window.py，依赖已安装（pip install -r requirements.txt）。

等高线不显示

平坦地形（城市街区）高程差为 0，只显示单条等高线。自然景观有起伏才能看到多条。

画图颜色全是空白

确保先完成求解再画图。颜色空白说明场数据未就绪。

φ-z 图不对称

数据本身是对称的（±30° 结果相同），但需要重启 GUI 后重新求解再画图。旧版本存在排序 bug 已修复。

添加点后旧点消失

已修复——添加是追加而非覆盖。如仍遇到，检查是否误点了"管理测量点"。
